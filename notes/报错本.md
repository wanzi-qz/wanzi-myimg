# 报错本

只记真踩过的坑。每条三段：现象 / 原因 / 修法。写完一条就少踩一次。

---

## 1. cv2.boxFilter 不接受 BORDER_WRAP

- 现象：`cv2.error: ... Unknown/unsupported border type`，参数化测试里只有 wrap 那一组炸。
- 原因：OpenCV 的 boxFilter 内核没实现环绕边界（别的滤波有），文档没写。
- 修法：基准侧改成 numpy 先 `np.pad(mode='wrap')` 补出环绕圈，再让 cv2 在补好的图上做
  `BORDER_CONSTANT` 均值，最后裁回原尺寸。均值这步仍由 OpenCV 独立算，对拍 max|err| 2.8e-14。
- 教训：对拍失败先怀疑「基准能不能这么调」，再怀疑自己的实现。

## 2. 契约测试里 canny 喂彩色图报的是 TypeError 不是 ValueError

- 现象：`test_rejects_color_input[canny]` 失败，抛 TypeError。
- 原因：测试只喂了一张图，canny 的 `low/high` 是必填位置参数，签名校验先炸，
  根本走不到 `check_gray` 的 ndim 检查。测的是「缺参数」而不是「拒彩色」。
- 修法：契约测试给每个算子配 `EXTRA_ARGS` 表，把参数喂足再喂彩色图。
- 教训：异常类型对上了不代表测到了想测的东西。

## 3. 闭运算填孔测试恒失败：孔数永远 ≥ 1

- 现象：`assert n == 0` 失败，n 至少是 1，甚至 3。
- 原因两个：(a) 把 `255 - out` 当前景标记时，图像外圈那一大片背景自己是一个连通域，
  直接数个数必然 ≥1；(b) k=5 填不满最大那个孔（直径约 10 像素）。
- 修法：只数不贴图像边界的背景连通域；并且把 k 从 3 到 9 逐个跑，把「哪个 k 填掉哪个孔」
  写成断言（83/45/20 → k=5 填 20、k=7 填 45、k=9 全平）。
- 教训：测试失败先打印中间量，别急着改断言。

## 4. CLAHE「暗块标准差提升」在 impulse / random_uint8 上不成立

- 现象：`out[tile].std() >= gray[tile].std() * 0.99` 在这两个用例上失败。
- 原因：不是 bug。这两个用例的直方图本来就摊满 0..255，CLAHE 的削峰只会把极端值往回收，
  标准差略降才是正确行为。拿它们测「对比度提升」是用例选错了。
- 修法：对比度断言只跑 uneven_light / microscope（本来就暗、有结构）；
  通用自洽性（dtype / 形状 / 确定性）所有用例都跑。
- 教训：断言要跟着「这个性质在什么条件下成立」走，不是跟着「所有输入」走。

## 5. Canny 在完美阶跃边上 IoU = 0（历史坑，已修）

- 现象：step_edge 用例 myimg 和 cv2 各检出 128 个边缘像素，IoU 却是 0。
- 原因：NMS 平局处理。阶跃两侧幅值完全相等，`>=` 用两边会留两像素宽的边，
  `>` 用两边会整条压掉；必须一松一严 `keep = (mag >= n1) & (mag > n2)`。
  松紧放哪一侧决定边落在左列还是右列，放反了就错开一列，IoU 归零。
- 修法：实测 cv2 保留左列，把松的一侧放在 E 邻居。
- 教训：像素数相同 ≠ 位置相同，IoU 这类指标对位移极其敏感。

## 6. cv2.GaussianBlur 喂 uint8 拿不到无损结果

- 现象：对拍误差 1e-2 量级，怎么查实现都查不出问题。
- 原因：GaussianBlur 不接受 ddepth 参数，输出深度跟随输入；uint8 进去先被截断成整数。
- 修法：基准侧统一喂 float64。boxFilter 有 ddepth 参数，两家 API 不一致。
- 教训：对拍前先把 dtype 链路画出来。

## 7. `from myimg import histogram` 拿到的是函数不是模块

- 现象：`myimg.histogram(img, 256)` 报「int 不可调用」之类的怪错。
- 原因：`myimg/__init__.py` 把 `histogram` 函数导出到了包命名空间，遮蔽了同名子模块。
- 修法：测试里用 `importlib.import_module("myimg.histogram")` 取模块。
- 教训：包级导出和子模块重名是 Python 的老坑，起名字时避开。

## 8. cv2.Canny 只收 CV_8U

- 现象：想把平滑后的 float 图放大 256 倍转 uint16 喂 Canny 做「无取整」对照，直接 assertion failed。
- 原因：这个版本的 Canny 只实现了 8U 路径。
- 修法：放弃这条对照路线，把带预平滑的 Canny 改成「只记录不对拍」，
  验收标准换成噪声抑制的功能性断言（见 tests/test_edges.py 最后两条）。
- 教训：对照实验设计要先确认基准 API 支持，别写完才发现路不通。

## 9. pytest 看不到 summary

- 现象：`pytest -q` 只出进度点，没有「xxx passed」那一行。
- 原因：pyproject 的 addopts 已经是 `-q`，命令行再给一个就是 `-qq`，summary 被关掉。
- 修法：要看 summary 就别在命令行加 `-q`。
- 教训：小坑也记，省得下次再花五分钟。

## 10. Windows 下中文文件读写

- 现象：脚本 print 中文报 GBK 编码错；读自己写的 md 乱码。
- 修法：一律 `python -X utf8`，写文件显式 `encoding="utf-8"`，
  PowerShell 写文件用 `Set-Content -Encoding UTF8`。
